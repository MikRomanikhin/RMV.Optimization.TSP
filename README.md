RMV.Optimization.TSP

A compact collection of discrete optimization algorithms for the Traveling Salesman Problem (TSP), implemented in C#.
The solution brings together several heuristic and metaheuristic approaches in a clean, modular structure. 

🚀 Key Features
Multiple TSP solvers: Local Search, Parallel Local Search, ACO, Beam Search, Pilot, PSO. 

Modular project layout with dedicated subprojects for algorithms, ants, domain, utilities, UI, and tests.

Fully written in C# (.NET).

Licensed under MIT.

📁 Project Layout
RMV.Optimization.TSP.Algorithms — Core algorithm implementations.

RMV.Optimization.TSP.Ants — Ant Colony Optimization.

RMV.Optimization.TSP.Domain — Domain models.

RMV.Optimization.TSP.Common — Shared utilities.

RMV.Optimization.TSP.Tests — Algorithm test suite.

RMV.Optimization.TSP.UI — UI and data files.

RMV.Optimization.TSP.sln — Solution file.
